Per-person stubs. Each is a thin ref note — name, domain, primary channels, why noticed. They grow as you add ref notes by or about the person; eventually some promote to `concepts/<name>.md` for synthesis.

The discovery queue for people not yet stubbed lives at [[antilibrary/people]].

## All people

```dataview
TABLE WITHOUT ID file.link AS "Person", description AS "Domain"
FROM #person
SORT file.name ASC
```
