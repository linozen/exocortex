# Python for Everybody — University of Michigan / Charles Severance

Beginner Python MOOC by Charles "Dr Chuck" Severance at U-Michigan. Free, browser-runnable exercises, free PDF textbook. Source: [py4e.com](https://www.py4e.com/), textbook at [py4e.com/book](https://www.py4e.com/book).

## Status

Worked through. Was the entry point into programming — no extracted concept notes because the material is foundational and would clutter the Zettel rather than augment it.

## What was covered

- Variables, expressions, statements
- Conditional execution, `try`/`except`
- Functions, parameters, return values
- Iteration: `while`, `for`, `break`, `continue`
- Data structures: strings, lists, dictionaries, tuples
- File I/O
- Regular expressions
- Networked programs and APIs
- (Touched: object-oriented programming, SQL with SQLite, data visualisation)
